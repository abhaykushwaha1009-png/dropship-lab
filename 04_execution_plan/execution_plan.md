# Execution Plan — AI Dropshipping 7-Day Challenge

## Goal
Replicate Mark Tilbury's AI dropshipping 7-day challenge: build a Shopify dropshipping store using only AI tools, with a $300 budget cap, targeting $1,000 in sales.

## Prerequisites (Owner Handles)
1. **Shopify account** — sign up, use $1/month trial if available
2. **Payment processor** — Stripe/PayPal connected to store
3. **Supplier accounts** — AliExpress/AutoDS/Teemdrop or similar
4. **Ad accounts** — Facebook Ads, TikTok Ads (as applicable)
5. **Email/capture tool** — Omnisend or similar (referenced in video)

## Day-by-Day Plan

### Day 1 — Niche & Research (Budget: $0)
- [ ] Pick random niche (use audience suggestions or product tool)
- [ ] Run product research using marketplace/tool
- [ ] Apply winning-product cheat sheet criteria
- [ ] Select 1–3 candidate products
- [ ] Deliverable: `03_method_breakdown/day1_niche_selection.md`

### Day 2 — Store Build (Budget: ~$29 Shopify first month)
- [ ] Create Shopify store
- [ ] Use AI store builder to generate store structure
- [ ] Configure basic settings (domain, currency, shipping)
- [ ] Deliverable: Live store URL

### Day 3 — Branding (Budget: $0–$50)
- [ ] Generate brand name, logo, colors via AI
- [ ] Apply brand to Shopify theme
- [ ] Write About Us, Contact, Policy pages
- [ ] Deliverable: Brand kit files

### Day 4 — Products (Budget: $0)
- [ ] Import winning products (AutoDS or manual)
- [ ] Write AI-optimized product titles/descriptions
- [ ] Set pricing with margin for $300 ad budget
- [ ] Deliverable: Product catalog live

### Day 5 — Ads (Budget: ~$250 remaining)
- [ ] Set up Facebook/TikTok ad account
- [ ] Generate AI ad creatives (UGC-style)
- [ ] Launch test campaigns ($50–$100/day)
- [ ] Deliverable: Active ad campaigns

### Day 6 — Review & Optimize (Budget: $0)
- [ ] Review sales data, CPC, CPA, ROAS
- [ ] Kill losing products/ads, scale winners
- [ ] Adjust pricing if needed
- [ ] Deliverable: Optimization report

### Day 7 — Final Profit Review (Budget: $0)
- [ ] Calculate: Revenue − (Ad spend + Shopify + apps) = Profit
- [ ] Compare vs $1,000 goal
- [ ] Decide: scale, pivot, or stop
- [ ] Deliverable: Final P&L report
